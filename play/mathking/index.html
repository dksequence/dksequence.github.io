수학킹

초등부터 대학까지 11랭크를 오르며 푸는 초등 수학 게임. 매일 수학 문제를 풀고 계급을 올리는 수학 문제 풀이 앱.

위 화면은 안드로이드 앱의 웹 버전입니다. 기기에서 쓰려면 아래에서 받으세요.

게임 소개

수학킹은 겉은 게임, 알맹이는 정통 수학 교육 앱입니다. 비기너(초등)부터 퍼펙마스터(대학 4학년)까지 11개 랭크를 오르며, 각 랭크에서 실제 교육과정에 맞는 문제 50개를 풀면 다음 랭크가 열립니다. 사칙연산·방정식·함수·미적분·행렬·확률까지 모든 문제는 기기 안에서 교육과정에 맞춰 자동 생성되고 정답과 풀이가 정확합니다. 게임 같은 랭크·뱃지·콤보로 재미있게 실력을 키웁니다.

이런 게임입니다

  • 초등~대학 11랭크 진행
  • 교육과정 정확 문제 자동 생성(정답·풀이 무오류)
  • 50문제 클리어로 랭크업
  • 정답 풀이 해설 제공
  • 랭크 로드맵·콤보·통계
