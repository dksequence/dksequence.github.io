DKSEQUENCE Pinterest Publishing Tool — Privacy Policy (English)

Tool: DKSEQUENCE Pinterest publishing integration (Pinterest API app) · Company: DKSEQUENCE · Last updated: 2026-09-21

1. What this tool does

This tool uses the Pinterest API to create and publish promotional Pins, on DKSEQUENCE's own Pinterest business account, for DKSEQUENCE's own apps published on Google Play. It is not a service offered to other companies or individuals, and it is not an app installed or logged into by end users.

2. Information we access

This tool only accesses the OAuth access token and boards/pins belonging to DKSEQUENCE's own Pinterest account. It does not access other Pinterest users' personal or private data, and it does not collect personally identifiable information (name, email, phone number, etc.) from app users or website visitors.

3. Data retention

The OAuth token is stored only on DKSEQUENCE's internal server/device and is not shared with third parties. We do not operate a separate user account system or personal-data database for this tool.
