My Habit Grid 개인정보처리방침 (Privacy Policy)

최종 수정: 2026-10-13 · 시행일: 2026-10-13 · 앱: My Habit Grid (com.dksequence.myhabitgrid) · 개발: DKsequence(주식회사 디케이시퀀스)

My Habit Grid는 계정·로그인 없이 동작하며, 개발자 서버가 없습니다. 앱은 이용자의 습관 기록을 개발자에게 전송하지 않습니다.

1. 수집·처리하는 정보

  • 습관 기록·설정: 습관 항목, 체크 기록, 알림 시각, 언어·화면 설정 등은 이용자의 기기 안(앱 내부 파일·SharedPreferences)에만 저장됩니다. 개발자에게 전송되지 않습니다.
  • 백업(내보내기): 이용자가 «내보내기»를 직접 실행할 때만 JSON 파일이 만들어지며, 이용자가 공유 시트에서 고른 위치에 저장됩니다. 개발자에게 전송되지 않습니다.
  • 자동 기록(선택 기능, 이용자가 켠 경우에만 동작)
  • 걸음 수: 기기의 걸음 센서(활동 인식 권한)를 사용해 기기 안에서만 계산하며, 하루 기준값을 기기에 저장합니다. 전송하지 않습니다.
  • 앱 사용 시간: 이용자가 설정에서 «사용 기록 접근»을 직접 허용한 경우, 이용자가 고른 앱의 «오늘» 사용 시간만 읽습니다. 기기 안에서만 처리하며 전송하지 않습니다. 실행 가능한 앱 목록은 «어느 앱?»을 고르는 화면에서만 사용합니다.
  • GitHub 기여: 이용자가 입력한 GitHub 공개 사용자명을 github.com 으로 보내 공개 기여 기록(일별 개수)을 가져옵니다(https://github.com/users/<사용자명>/contributions). 전송되는 것은 사용자명과 일반적인 네트워크 요청 정보(IP 주소, 기기 정보)이며, 개발자 서버를 거치지 않습니다.
  • 사용 통계(Google Firebase 애널리틱스): 앱 개선을 위해 앱 실행·화면 이용 같은 이벤트, 앱 인스턴스 ID, 기기 종류·OS 버전·대략적 지역을 Google에 보내 개발자가 익명 통계로 봅니다. 습관 이름·기록·메모·GitHub 사용자명은 보내지 않습니다.
  • 홈 화면 위젯: 기기 안 저장소의 습관 요약만 표시하며 전송하지 않습니다.
  • 알림: 습관 알림·하루 체크 알림은 기기 안에서 예약되며 서버를 사용하지 않습니다.
  • 인앱결제: 광고 제거(1회성 상품) 구매는 Google Play 가 처리하며, 개발자는 결제 수단 정보를 받지 않습니다.

  • AdMob은 광고 제공·분석·부정 사용 방지를 위해 광고 식별자(Advertising ID), 기기 정보, 앱 사용 정보 등을 수집할 수 있습니다(Google 정책).

My Habit Grid Privacy Policy

Last updated: 2026-10-13 · Effective: 2026-10-13 · App: My Habit Grid (com.dksequence.myhabitgrid) · Developer: DKsequence (DK Sequence Co., Ltd.)

My Habit Grid works without any account or sign-in, and there is no developer server. The app does not send your habit records to the developer.

1. Information we collect and process

  • Habit records and settings: habits, check-in records, reminder times, language and display settings are stored only on your device (app files and SharedPreferences). They are not sent to the developer.
  • Backup (export): a JSON file is created only when you run "Export", and it is saved where you choose in the share sheet. It is not sent to the developer.
  • Automatic tracking (optional; works only if you turn it on)
  • Steps: uses the device step sensor (activity recognition permission); calculated only on the device, and a daily baseline value is stored on the device. Nothing is transmitted.
  • App usage time: only if you grant "Usage access" in system settings yourself, the app reads today's usage time of the apps you pick. It is processed only on the device and is not transmitted. The list of launchable apps is used only on the "Which app?" picker screen.
  • GitHub contributions: the GitHub public username you enter is sent to github.com to fetch your public contribution record (daily counts) (https://github.com/users/<username>/contributions). What is sent is the username and ordinary network request information (IP address, device information); it does not pass through any developer server.
  • Usage statistics (Google Firebase Analytics): to improve the app, events such as app launches and screen use, the app instance ID, device model, OS version and approximate region are sent to Google so the developer can see anonymous statistics. Habit names, records, notes and the GitHub username are not sent.
  • Home screen widget: shows a summary of habits from on-device storage only; nothing is transmitted.
  • Notifications: habit and daily check reminders are scheduled on the device; no server is used.
  • In-app purchase: the Remove Ads one-time purchase is processed by Google Play; the developer does not receive your payment details.

3. Advertising (Google AdMob)

  • The app shows Google AdMob ads: banner (detail and settings screens), interstitial (occasionally after you close a detail screen), and rewarded (a button you tap to pause banners for 24 hours).
  • AdMob may collect the Advertising ID, device information and app usage information to serve ads, for analytics and for fraud prevention (per Google policy).
  • Users in the European Economic Area (EEA) see a consent form from Google's User Messaging Platform (UMP), which you can change later in settings.
  • Google policy: https://policies.google.com/privacy · Controls: device Settings > Google > Ads.

5. Children

  • This app is intended for general users aged 13 and over and is not directed to children. The developer does not collect children's personal information.

6. Data retention, deletion and your rights

  • Data retention: habit records and settings are not collected or retained by the developer; they stay on your device until you delete them.
  • Deletion: on-device data is deleted when you uninstall the app. You can also delete habits and records inside the app.
  • Backup files: a JSON file made with "Export" stays where you saved it, so you need to delete it yourself.
  • Automatic tracking: steps, app usage time and GitHub tracking can be turned off, and the permissions revoked, in settings.
  • Advertising data: handled under each provider's (Google) policy and controllable in your device's ad settings.
