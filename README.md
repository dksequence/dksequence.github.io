# DKsequence — 36 Android apps, and what each one actually solves

This repository is the source for **[dksequence.com](https://dksequence.com)**. It publishes 36 Android apps on Google Play — tools for things like getting water out of a phone speaker, measuring noise in decibels, counting pushups without a camera, and telling what a dog's bark means — alongside puzzle and party games.

Every app below is listed with **what problem it solves** and **the questions people actually type into search** (measured with Google autocomplete, not guessed). If you are looking for one of those answers, the linked page explains how to do it — including how to do it without any app.

## How these apps are built

Most are Flutter; a few are Capacitor with a web core. They are built and released through an in-house pipeline that generates store listings in 12 languages (Korean, English, Japanese, Traditional/Simplified Chinese, Thai, Malay, Indonesian, Spanish, French, Portuguese, German), checks every string against a banned-phrase linter before it can ship, and verifies the result against the live store rather than the local source.
