InstaTorch — 딱 한 번 누르면 이미 켜져 있는 손전등

■ 왜 더 빠른가
휴대폰 기본 손전등은 화면 켜기 → 화면 내려서 빠른설정 열기 → 타일 누르기, 최소 2~3번의 동작이 필요합니다.
InstaTorch는 다릅니다. 아이콘을 누르는 순간 손전등이 이미 켜져 있습니다. 행동은 딱 1번, 앱을 여는 것뿐입니다.
다시 아이콘을 누르면 그대로 꺼집니다.

■ 특징
· 아이콘 탭 1번 = 즉시 점등, 재탭 1번 = 즉시 소등
· 밝기 단계 조절(지원 기기)
· SOS 모스부호 신호
· 홈 화면 위젯·퀵설정 타일 — 앱을 열지 않고도 켜고 끄기
· 손전등에는 카메라 권한만 필요(켜짐 알림용 알림 권한은 선택), 언어 설정은 한 번 고르면 유지

※ 카메라의 LED를 사용하는 손전등 도구이며, 위치·마이크·연락처 권한을 요청하지 않습니다.
