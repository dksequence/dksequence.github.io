SafeJot

생산성 자동저장·버전기록·휴지통·백업까지, 실수로도 안 사라지는 메모장.

대표 이미지

소개 영상

스크린샷

앱 소개

메모는 쓰는 순간 사라지면 안 됩니다. SafeJot은 저장 버튼이 필요 없습니다 — 입력을 멈추면 자동으로 저장되고, 화면을 나가거나 앱을 전환해도 그대로 남습니다.

■ 신뢰 엔진
• 자동저장: 저장 버튼·로딩 스피너 없이 바로 반영
• 버전 기록: 저장할 때마다 이전 버전이 남아 언제든 되돌릴 수 있습니다
• 휴지통 30일: 지운 메모도 30일간 보관, 복원하거나 영구 삭제
• 직접 고른 폴더로 백업: 주기적으로 전체 메모를 파일 하나로 내보냅니다
• 시작할 때 무결성 검사: 문제가 생기면 최신 백업으로 복구를 제안합니다

■ 정리하고 찾기
• 색상 카드 태그로 한눈에 구분
• 별점과 왕관으로 중요한 메모를 표시
• 폴더: 기본 목록은 미분류만 보여주고, "전체보기"로 폴더까지 한 번에, 폴더 전용 화면도 있습니다
• 검색어가 실제로 어디 있는지 강조해서 보여줍니다
• 길게 눌러 여러 개를 한 번에 선택 → 일괄 삭제·폴더 이동

■ 표현하기
• 이모티콘 삽입, 컬러 구분선으로 본문 구획 나누기
• 메모별로 글자 크기를 따로 키우거나 줄이기
• 메모 하나에 짧은 음성 한 조각(최대 60초) 첨부 — 기기 안에만 저장
• 제목+본문을 텍스트로 바로 공유

■ 그 외
• 중요한 메모는 생체인증이나 PIN으로 따로 잠그기
• 홈 화면 위젯 2종: 새 메모 바로 쓰기·최근 메모 목록
• 계정 로그인, 클라우드 동기화 없이 전부 기기 안에서 처리됩니다

■ 알아두세요
• 앱에 광고가 있습니다. 광고 제거 상품을 구매할 수 있습니다
