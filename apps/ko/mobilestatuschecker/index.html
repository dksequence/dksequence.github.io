모바일 상태 체커

도구 하드웨어 스펙부터 성능 벤치마크, 배터리·기기 검사까지 한 앱에서 확인하세요.

대표 이미지

소개 영상

스크린샷

앱 소개

중고폰을 사고팔 때, 또는 지금 쓰는 폰 상태가 궁금할 때 필요한 정보를 한 곳에서 확인합니다.

Mobile Status Checker는 하드웨어 스펙 확인, 실시간 성능 모니터링, 벤치마크, 중고폰 검수 도구를 한 앱에 담았습니다.

■ 하드웨어 정보
• OS·기기 모델·CPU·RAM·저장공간·배터리·디스플레이·네트워크 정보를 확인합니다
• 배터리 온도·전압·상태(health)까지 함께 표시합니다

■ 실시간 모니터
• 배터리 온도·잔량, RAM 사용률을 그래프로 실시간 확인합니다
• 부하 테스트로 기기가 부하 상황에서 어떻게 반응하는지 볼 수 있습니다

■ 성능 벤치마크
• 정수 연산·부동소수점 연산·메모리 처리 속도를 측정해 종합 점수를 냅니다
• 외부 벤치마크 앱과 점수를 직접 비교할 수는 없습니다(측정 방식이 다릅니다)

■ 중고폰 스펙 위변조 확인
• 삼성 갤럭시 주요 기종의 공식 스펙(RAM·코어 수·배터리 설계용량)과 실제 기기 값을 대조합니다
• 기종을 특정할 수 없거나 대조 데이터가 없으면 "비교불가"로 정직하게 표시합니다

■ 배터리 상태
• 설계 용량 대비 실제 충전 용량으로 배터리 열화 정도를 확인합니다
• 배터리 잔량이 낮을 때는 오차가 커질 수 있어 안내 문구를 함께 보여줍니다

■ 지속성능 테스트
• 일정 시간 연속 부하를 준 뒤 성능이 처음 대비 얼마나 유지되는지 측정합니다(스로틀링 확인)

■ 기기 검사
• 터치(격자 드래그로 사각지대 확인)・화면(색상·얼룩)・스피커・마이크・진동・센서 6가지를 하나씩, 또는 순서대로 검사합니다
• 검사 결과를 카드 이미지로 캡처해 공유할 수 있습니다

■ 알아두세요
• 앱 안에서 언어를 선택할 수 있습니다(12개 언어)
• 앱에 광고가 있습니다. 광고 제거 상품을 구매하면 배너·전면 광고가 사라집니다
• 마이크 테스트의 임시 녹음 파일은 테스트가 끝나면 즉시 삭제하고 서버로 보내지 않습니다
