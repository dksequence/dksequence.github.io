턴버즈

도구 버튼 한 번으로 턴을 넘기는 타이머. 바둑·장기·루미큐브 같은 보드게임에.

대표 이미지

소개 영상

스크린샷

앱 소개

바둑, 장기, 루미큐브, 카드게임처럼 순서대로 돌아가는 게임에서 "한 사람이 너무 오래 고민한다"는 문제를 해결하는 가장 단순한 타이머입니다.

■ 켜자마자 바로 쓴다
앱을 열면 큰 타이머와 시간만 보입니다. 로그인도, 튜토리얼도, 복잡한 메뉴도 없습니다. 화면을 누르면 정해진 시간만큼 카운트다운이 시작되고, 시간이 다 되면 부저가 울립니다. 다음 사람이 다시 누르면 같은 시간이 새로 시작됩니다.

■ 소리로 알려줍니다
· 남은 시간이 10초가 되면 매초 짧은 신호음이 울립니다
· 0초가 되면 확실하게 구분되는 부저음이 울립니다
· 초음과 종료음을 따로 끌 수 있습니다. 두 버튼 모두 첫 화면에 있어서 설정에 들어가지 않아도 됩니다
· 스킨마다 서로 다른 초음·종료음이 짝지어져 있습니다

■ 시간과 표시 방식을 고를 수 있습니다
· 길이: 10초 / 30초 / 1분 / 3분 / 5분 / 10분 프리셋, 원하는 값 직접 입력도 가능
· 표시 형식: 분:초 / 시:분:초 / 밀리초까지 3가지

■ 스킨 40종
같은 타이머를 40가지 다른 모습으로 볼 수 있습니다. 기본 스킨 20종은 처음부터 바로 쓸 수 있습니다. 선명한 링, LED 세그먼트 링, 남은 시간이 원판으로 줄어드는 비주얼 타이머, 플립 시계, 네온, 아날로그 시계, 파이 차트, 스톱워치, 주방 타이머 등. 여기에 바늘 다이얼, 금속 게이지, 하프톤 블록 같은 프리미엄 스킨 20종이 더 있으며, 한 번 구매로 전부 열립니다.

■ 이런 분께
· 바둑·장기 대국에서 한 수 제한시간을 두고 싶은 분
· 루미큐브·보드게임 모임에서 진행 속도를 지키고 싶은 분
· 발표·토론·게임에서 1인당 시간을 공평하게 나누고 싶은 분

■ 구매 항목
· 광고 제거
· 프리미엄 스킨 20종 잠금 해제

광고가 포함되어 있습니다. 광고는 설정 화면에서만 표시되며, 대국이 진행되는 타이머 화면은 그대로 유지됩니다.
