Dice Box 3D

캐주얼 흔들면 굴러가는 3D 주사위 굴리기 앱. 보드게임·TRPG·랜덤 결정에 주사위 개수와 면을 자유롭게 골라 던지는 주사위 게임.

앱 소개

손 안의 진짜 주사위 상자, Dice Box 3D!

화면을 탭하거나 폰을 흔들면 3D 주사위가 상자 안에서 부딪히고 회전하며 자연스럽게 멈춥니다. 단순 난수 생성기가 아니라, 진짜 주사위를 흔든 듯한 물리적 손맛이 핵심입니다.

■ 진짜 같은 물리
· 주사위끼리·벽과 부딪히는 3D 충돌과 회전
· 또르르 굴러 자연스럽게 멈추는 감속
· 충돌 사운드 + 진동 햅틱

■ 간단한 사용
· 탭 또는 흔들기로 굴리기
· 주사위 1~4개 선택
· 멈추면 각 눈과 합계를 바로 표시

■ 프리미엄(PRO)
· 주사위 색(검정·파랑·빨강·형광) · 재질(나무·유리·금속) · 테마(미드나잇·느와르·마젠타·네온)
· 광고 제거로 PRO 전체 잠금 해제 — 광고 보고 미리보기도 가능

보드게임, TRPG, 술게임, 빠른 랜덤 결정 — 주사위가 필요할 때 Dice Box 3D.
