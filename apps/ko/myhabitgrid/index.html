My Habit Grid

생산성 하루 한 칸, 한 해가 한눈에. 위젯으로 앱을 열지 않고 바로 체크

대표 이미지

소개 영상

스크린샷

앱 소개

My Habit Grid — 하루를 칸 하나로 채워 가는 습관 기록 앱입니다. 습관을 만들고 매일 기록하면 칸이 하나씩 채워지며 한 해의 흐름이 한눈에 보입니다. 오늘 할 일은 체크 목록으로, 한 주는 7일 칸으로, 길게는 26주·53주 그리드로 확인할 수 있습니다.

■ 특징
· 보기 3종: 오늘(체크 목록) · 주간(최근 7일 칸) · 그리드(최근 26주 칸)
· 습관 상세: 53주 전체 그리드, 지난 날도 고칠 수 있는 월 달력, 달별·요일별 통계, 메모
· 습관 종류 2가지: «만들기»와 «끊기·줄이기» — 끊기·줄이기는 기록 없는 날을 지킨 날로 치고, 한도 이하면 성공
· 기록 방식 4가지: 했다/안 했다 · 횟수(예: 물 8잔) · 시간(스톱워치 포함) · 수치(단위·소수 가능)
· 연속 기록 목표: 없음 / 매일 / 주 N일 / 월 N일 — «쉬는 날»은 연속 기록을 끊지 않음
· 알림: 습관마다 최대 3개(요일·시각 선택), 이미 한 날은 알림을 건너뜀. 선택한 시각에 «오늘 남은 습관»을 알려 주는 하루 체크 알림
· 홈 화면 위젯 2종: «오늘»(최대 5개 습관을 앱을 열지 않고 바로 체크) · «그리드»(고른 습관의 최근 26주 칸)
· 자동 기록 3종(선택): 걸음 수 · 앱 사용 시간(줄이기 습관에 적합) · GitHub 공개 기여
· 화면 테마 2종: «정원 일지»(밝음, 따뜻한 종이 위 텃밭) · «유리 모자이크»(어두움, 남색 위 빛나는 유리 타일)
· 백업 내보내기·가져오기(JSON 파일 하나), 보관함, 길게 눌러 순서 변경, 분류 필터
· 12개 언어와 앱 안 언어 선택기, 진동 반응(끌 수 있음)
· 기록과 설정은 기기 안에만 저장되며 계정·로그인이 필요 없습니다

※ 안내
· 광고: 배너는 습관 상세·설정 화면 하단에만 표시되고, 상세 화면을 닫은 뒤 가끔 전면 광고가 나옵니다. 체크하는 순간에는 광고가 표시되지 않습니다. 설정에서 «광고 제거»(1회 결제)와 «배너 24시간 쉬기»(보상형 광고 1회 시청)를 쓸 수 있습니다.
· 자동 기록은 사용자가 직접 허용해야 동작합니다. 앱 사용 시간은 사용 기록 접근을 직접 허용해야 하며, 걸음 수·앱 사용 시간은 기기 안에서만 처리됩니다. GitHub 은 입력한 사용자명만 github.com 으로 전송됩니다.
· 알림을 받으려면 알림 권한을 허용해야 합니다.
